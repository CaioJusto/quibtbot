Instalar neste computador

O app prepara tudo sozinho. Se o Docker não estiver instalado, o Quibt baixa a versão oficial, pede a senha do Mac uma vez, abre o Docker e continua automaticamente.

Ao começar, você aceita os termos de uso do Docker Desktop. O Quibt verifica a assinatura oficial antes de instalar.
